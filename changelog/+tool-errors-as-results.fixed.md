An error raised while a tool runs now returns a tool result with `isError: true` that carries the error message and any remediation hint, as the MCP specification requires. This covers, for example, `get_nodes` with an unknown kind, a response over the size limit, a GraphQL mutation sent to `query_graphql`, and Infrahub SDK errors such as an unreachable Infrahub instance or a rejected API token. Since the upgrade to FastMCP 4 and MCP SDK 2, these errors reached the client as a JSON-RPC `-32603 Internal error`. Unknown tools, invalid arguments, calls to write tools on a read-only server, and requests without passthrough credentials still return JSON-RPC errors.
