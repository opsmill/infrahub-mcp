A failed tool call, such as `get_nodes` with an unknown kind, an oversized response or a GraphQL mutation sent to `query_graphql`, now returns a tool result with `isError: true` that carries the error message and remediation hint, as the MCP specification requires. Since the upgrade to FastMCP 4 and MCP SDK 2, these failures reached the client as a JSON-RPC `-32603 Internal error`. Unknown tools, invalid arguments, read-only rejections and missing credentials still return JSON-RPC errors.
