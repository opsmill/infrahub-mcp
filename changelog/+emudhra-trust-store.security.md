The container image rejects certificates that chain through the compromised eMudhra intermediate CAs ([incident page](https://emudhra.we-have-a-problem.com/)). The build stage moves to uv 0.13.6 on Debian trixie. The runtime stage upgrades `ca-certificates` and stops the build if the installed version is older than `20250419+deb13u1`. Before the image workflow pushes an image, it now checks that the incident's test hosts fail certificate verification from inside the image, with both Python and curl.
