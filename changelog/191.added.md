The server now sends instructions to every MCP client: read the schema with `get_schema` before querying, which tool to use for common questions, and how filter keys differ between `get_nodes` and GraphQL. Tool descriptions name `get_schema` directly, `query_graphql` explains how to fix a rejected `filters` argument, the schema resources accept `?branch=`, and `INFRAHUB_MCP_RESOURCES_AS_TOOLS=true` adds `list_resources` and `read_resource` for clients that pass only tools.
