Share a hash-validated schema cache across sessions in passthrough modes, so repeated schema reads hit one process-wide entry per branch instead of refetching per caller. Each hit is validated against the branch schema hash, every caller's credential is checked before an entry is served, and revalidation is throttled by `INFRAHUB_MCP_SCHEMA_CACHE_TTL`. Tune it with `INFRAHUB_MCP_SCHEMA_CACHE_ENABLED`, `INFRAHUB_MCP_SCHEMA_CACHE_MAX_BRANCHES`, `INFRAHUB_MCP_SCHEMA_CACHE_MAX_CONSECUTIVE_FAILURES`, and `INFRAHUB_MCP_SCHEMA_CACHE_MAX_STALENESS_SECONDS`.
