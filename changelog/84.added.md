Share a hash-validated schema cache across sessions, so repeated schema reads hit one process-wide entry per branch instead of refetching per caller. Within the `INFRAHUB_MCP_SCHEMA_CACHE_TTL` skip-window an entry is served without contacting Infrahub; past it, the entry is revalidated against the branch schema hash. In the passthrough modes every caller's credential is checked before an entry is served. Tune it with `INFRAHUB_MCP_SCHEMA_CACHE_ENABLED`, `INFRAHUB_MCP_SCHEMA_CACHE_MAX_BRANCHES`, `INFRAHUB_MCP_SCHEMA_CACHE_MAX_CONSECUTIVE_FAILURES`, and `INFRAHUB_MCP_SCHEMA_CACHE_MAX_STALENESS_SECONDS`.
